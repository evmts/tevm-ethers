# Getting started

## Install

`@tevm/ethers` is published to npm as [`@tevm/ethers`](https://www.npmjs.com/package/@tevm/ethers).
`ethers`, `tevm`, and `viem` are **peer dependencies** so your application picks the versions.

:::code-group

```bash [pnpm]
pnpm add @tevm/ethers ethers tevm@1.0.0-next.149 viem@2.46.0
```

```bash [npm]
npm install @tevm/ethers ethers tevm@1.0.0-next.149 viem@2.46.0
```

```bash [yarn]
yarn add @tevm/ethers ethers tevm@1.0.0-next.149 viem@2.46.0
```

```bash [bun]
bun add @tevm/ethers ethers tevm@1.0.0-next.149 viem@2.46.0
```

:::

### Supported ranges

| Peer dependency | Supported range          | Notes                                                                     |
| --------------- | ------------------------ | ------------------------------------------------------------------------- |
| `ethers`        | `>=6.0.0 <7`             | ethers v6 only. v5 is not supported.                                       |
| `tevm`          | `>=1.0.0-next.149 <2`    | Use the Tevm 1.x line.                                  |
| `viem`          | `>=2.37.9 <=2.46.0`      | Pinned upper bound: current Tevm packages reference chain definitions removed after viem 2.46.0. |

Use Node 24; the package is ESM-first and also ships a CommonJS build.

## Your first provider

```ts twoslash
// @noErrors
import { TevmProvider } from '@tevm/ethers'

const provider = await TevmProvider.createMemoryProvider({
	miningConfig: { type: 'auto' },
})

const chainId = await provider.send('eth_chainId', [])
const blockNumber = await provider.getBlockNumber()

console.log({ chainId, blockNumber }) // { chainId: '0x384', blockNumber: 0 }
```

`createMemoryProvider` creates a fresh in-memory Tevm node and wraps it in an ethers provider. The
default chain id is `900` (`0x384`), the Tevm default devnet chain.

## Reading a balance and sending a transaction

Tevm ships prefunded accounts, so you can sign and send a real transaction immediately.

```ts twoslash
// @noErrors
import { TevmProvider } from '@tevm/ethers'
import { PREFUNDED_PRIVATE_KEYS } from '@tevm/utils'
import { Wallet, parseEther, formatEther } from 'ethers'

const provider = await TevmProvider.createMemoryProvider({
	miningConfig: { type: 'auto' },
})

const wallet = new Wallet(PREFUNDED_PRIVATE_KEYS[0], provider)
const recipient = `0x${'42'.repeat(20)}`

console.log(formatEther(await provider.getBalance(wallet.address))) // '1000.0'

const tx = await wallet.sendTransaction({ to: recipient, value: parseEther('1') })
const receipt = await tx.wait()

console.log(receipt?.status) // 1
console.log(formatEther(await provider.getBalance(recipient))) // '1.0'
```

With `miningConfig: { type: 'auto' }` a block is mined for every transaction, so `tx.wait()`
resolves without any extra step. Without it, mine manually with `await provider.tevm.mine()` or
`await provider.send('tevm_mine', [{ blockCount: 1 }])`.

## Reusing an existing Tevm node

If you already created a Tevm node, pass it straight to the constructor rather than creating a
second EVM. The node must be extended with `tevmActions()` and `tevmSend()` — that is exactly what
`createMemoryProvider` does internally.

```ts twoslash
// @noErrors
import { TevmProvider } from '@tevm/ethers'
import { tevmActions, tevmSend } from '@tevm/decorators'
import { createTevmNode } from '@tevm/node'

const node = createTevmNode().extend(tevmActions()).extend(tevmSend())

const provider = new TevmProvider(node)

console.log(await provider.getBlockNumber()) // 0
```

A viem `MemoryClient` from `tevm` exposes its node at `client.transport.tevm`, so you can share one
EVM between viem and ethers:

```ts twoslash
// @noErrors
import { TevmProvider } from '@tevm/ethers'
import { tevmActions, tevmSend } from '@tevm/decorators'
import { createMemoryClient } from 'tevm'

const client = createMemoryClient()
await client.tevmReady()

const provider = new TevmProvider(client.transport.tevm.extend(tevmActions()).extend(tevmSend()))

console.log(await provider.getBlockNumber()) // 0
```
